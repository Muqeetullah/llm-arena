## Build mandate

Ship a complete evaluation workspace with clear navigation, readable model answers and useful empty, loading and error states.

## Character and direction

Use Georgia for display headings and the existing Geist family for interface text. A green italic highlight adds character to the welcome headline. Retain LLM Arena branding and labelled navigation.

## Composition patterns

Welcome: headline, supporting copy, composer, prompt starters, accuracy note. Active conversations: neutral response cards and docked composer. Catalogue and leaderboard: editorial introduction, filters and structured data.

## Component rules

Use green for primary actions and focus. Winners also carry an explicit label and icon. Keep avatars neutral. Prefer subtle rules and shallow shadows. All colour values live in app/globals.css.

## Responsive and accessibility direction

Light theme only, as requested. Keep the existing mobile drawer. Stack starter cards on small screens, wrap model chips and retain visible focus indicators. Respect reduced motion.

## Verified contrast

Primary text on canvas: 14.58:1. Secondary text: 5.70:1. Muted text: 4.92:1. White text on green actions: 7.00:1.
